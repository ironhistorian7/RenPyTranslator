실행할 작업

번역은 완료한 부분을 이어서 진행합니다. 재번역은 선택한 모델로 처음부터 번역해 별도 결과로 저장합니다. 기존 결과는 그대로 남습니다.

재번역은 준비된 프로젝트가 필요하며, 비교용 작업 사본을 만들 공간을 추가로 사용합니다. 취소한 재번역은 같은 모델로 다시 실행하면 이어집니다.

사용 방식

        

        
자동 선택은 모델이 한 GPU에 들어가면 해당 장치를 우선 사용합니다.
장치 사용량은 시스템 전체 수치입니다. ‘번역에 사용 중’은 이 프로그램의 모델 프로세스가 확인된 장치에만 표시합니다.

        

      

      
번역 과정
  1. 원문 정리스크립트에서 대사·선택지·UI를 모으고, 변수와 서식 태그를 보존합니다.
  2. 로컬 번역선택한 모델이 주변 원문과 인명 표기를 참고해 한국어로 번역합니다. 전체 줄거리 사전 분석은 자동 실행하지 않습니다.
  3. 검사와 보정태그·변수 누락을 검사하고, 실패한 항목을 복구한 뒤 인명·폰트·표시를 보정합니다.
  4. 결과 저장저장된 번역은 재사용하고 결과 폴더와 복사용 패치를 만듭니다. 정답·선택지 힌트는 선택했을 때만 추가합니다.

      
프로그램 위치
프로그램·설정·모델은 포터블 폴더에 보관합니다. 다른 PC로 옮길 때는 폴더 전체를 복사하세요.
